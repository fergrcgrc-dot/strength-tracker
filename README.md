# Strength Tracker (Registro de fuerza)

Aplicación de registro de entrenamiento de fuerza, publicada originalmente como un [Claude Artifact](https://claude.ai/artifact/K3MGVG2AACo4rBFjzAKkAq).

`index.html` contiene la aplicación completa (HTML/CSS/JS autocontenido). Cada versión queda registrada en el historial de commits de este repositorio.

## Uso

Abre `index.html` en el navegador, o sirve la carpeta con cualquier servidor estático.
